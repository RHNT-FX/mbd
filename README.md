# Sistem Tiket Konser (MBD Project)
Proyek ini adalah implementasi tugas akhir Manajemen Basis Data (MBD) menggunakan PostgreSQL dan Node.js Express.
Semua persyaratan seperti Triggers (3), Stored Procedures, Views, dan B-Tree Indexing sudah diterapkan dengan benar pada database.

Untuk panduan instalasi dan serah terima, silakan baca file `ex.md`.
